# DailyNoteのチェックリストを明日へ繰り越す3手順

DailyNoteに書いた未完了のチェックは、放っておくと当日のノートに埋もれていきます。翌日を開いても前日分は反映されず、結局その日のノートをさかのぼって確認する羽目になった。そんな経験のある方も多いはずです。

原因は、DailyNoteの仕組みそのものにあります。日付ごとに新規ファイルを作る前提のため、前日の未完了行は自動では引き継がれません。

この記事では、未完了チェックだけを明日のDailyNoteへ移す3手順と、二重管理になりやすいポイントを整理します。

> **今日の結論**
> - 未完了チェックだけを翌日へ繰り越すと、DailyNoteが「今日の作業面」として機能し続ける
> - 完了済みの行は繰り越さない。元ノート側に残すか削除するかを先に決めておく
> - テーマ変更やホットキー設定の話ではなく、今日のノートから明日のノートへ内容を移す運用そのものが本題
> - 貼り付けて終わりにせず、明日ノートで実際にトグルできるかまで確認する

## なぜ繰り越しが必要なのか

DailyNoteは、日付ごとに新規のファイルを作る前提のノートです。プラグインが行うのはファイルの新規生成までで、前日のチェック状態や行の中身を自動で転記する機能は持ちません。だから、未完了タスクをそのままにしておくと、翌日のノートを開いても「今日やること」が一目で分からなくなります。

放置した未完了行は、日を追うごとに前日・前々日のノートへ分散していきます。結局どのノートに何が残っているか把握できなくなり、繰り越しを後回しにするほど手間が増える。ここを先に断ち切るのが繰り越しです。

## 繰り越しの3手順

1. **今日のDailyNoteで未完了（`- [ ]`）だけを抽出する**
   完了済み（`- [x]`）の行は対象に含めません。抽出の時点で仕分けておくと、あとの手順で迷わずに済みます。
2. **明日のDailyNoteへ貼り、元ノート側は完了済みだけ残すか削除する**
   どちらの運用にするかは、貼り付ける前に決めておきます。都度判断を変えると、あとで見返したときにどちらのノートが正か分からなくなります。
3. **明日ノートでチェックがトグルできることを確認する**
   貼り付けた直後にクリックし、チェックが入るかまで見ます。ここまで確認して、繰り越し作業は完了です。

before/afterのイメージは次のとおりです。

```md
# 今日のDailyNote（繰り越し前）
- [ ] 資料をまとめる
- [x] 打ち合わせに参加する
- [ ] レビュー依頼を送る

# 明日のDailyNote（繰り越し後）
- [ ] 資料をまとめる
- [ ] レビュー依頼を送る
```

## つまずきやすいポイント（完了済みの二重管理）

筆者が試した範囲（2026年7月24日時点）では、完了済みの行を消さずに残したまま繰り越すと、明日ノート側に同じタスクが重複して並び、どちらが最新か分からなくなったことがあります。繰り越し対象を「未完了だけ」に絞ると決めておけば、この重複は起きにくいです。

もう一つ、貼り付けたあとのトグル確認を省略すると、コピー時にインデントがずれてチェックが利かない行が交ざっていても気づけません。親子関係の崩れは、貼ってすぐクリックして確かめるまでが繰り越し作業の一部。そう考えておくと手戻りが減ります。

## 繰り越し前後のチェック表

| 項目 | 今日のDailyNote | 明日のDailyNote |
| --- | --- | --- |
| 未完了（`- [ ]`） | 抽出して繰り越し対象にする | 貼り付けてトグル確認する |
| 完了済み（`- [x]`） | 残すか削除するかを決めて統一する | 繰り越さない |
| ネストした子タスク | 親と同じインデント幅を維持したまま抽出する | 親子関係が崩れていないか確認する |

## まとめ・次に読む

未完了だけを明日ノートへ移す運用に絞れば、DailyNoteは「今日の作業面」であり続けます。完了済みを混ぜないこと、貼り付け後にトグル確認すること。この2点を先に決めておくだけで、繰り越し作業の手戻りは減らせます。
