# ヘッダー直下のPR開示は警戒されない短文にする

アフィリエイトや広告を含むブログを運営していると、PR開示をどう書くか、どこに置くかで迷いやすい。派手な帯や強い色で目立たせると、記事を読み始める前に読者が身構えてしまうことがあります。かといって開示を目立たなくしすぎると、「隠しているのでは」という印象や、表示の分かりやすさへの疑問につながりかねません。

この記事では、サイト説明とPR開示をヘッダー直下にまとめ、警戒されにくい短文で伝える書き方の考え方を1分で読める範囲にまとめます。法令の解釈そのものではなく、文面とデザインの工夫が中心です。

> **今日の結論**
> - サイト説明とPR開示はヘッダー直下にまとめてよい（サイトの基本情報として並べる考え方）
> - 断定やクリック煽りは書かず、「記事により広告・アフィリエイトを含む場合があります」程度の落ち着いた表現に留める
> - 主役はサイト説明にし、PR注記はトーンを抑えつつも、読者から見て分かりにくくなるほど小さく・薄くはしない

## なぜPR開示だけ目立たせると警戒されやすいのか

PR開示だけを大きな帯や強い色で独立させて出すと、読者は「これは広告なんだ」という情報だけを先に受け取り、本文を読む前に距離を置いてしまうことがあります。サイト説明（このサイトが何を扱っているか）と並べて自然な文脈に置くと、PR開示は「サイトの基本情報の一部」として受け取られやすくなる。表示の内容は同じでも、並べる相手によって受け取られ方が変わる、という仕組みです。

## ヘッダー直下にまとめる書き方

1. 全ページ共通のサイト説明を1行で用意する（サイトが何を扱っているか）
2. ブログ配下のページだけ、サイト説明の続きにPR短文を足す（条件付き表示で対応できます）
3. 「記事により広告・アフィリエイトを含む場合があります」程度の、事実を淡々と伝える表現にとどめる
4. 文字サイズや色味は落ち着かせつつも、読者が普通に読める大きさ・コントラストは保つ

サイト説明とPR短文を1つの文脈にまとめると、次のような形になります。

```text
初心者向けにAI活用・開発ツールの使い方を紹介するブログです。
記事により広告・アフィリエイトを含む場合があります。
```

## 視認性は下げすぎない

「警戒されない短文にする」ことと、「表示を分かりにくくする」ことは別の話です。ステルスマーケティングに関する規制では、広告であることが一般消費者にとって分かりにくい表示が問題視されています。トーンを抑えるのは文面の書き方の範囲にとどめ、文字サイズを極端に小さくしたり、背景色に溶け込ませて読みにくくしたりする対応は避けたほうが安全だと考えられます。

筆者が確認した範囲では、景品表示法やステルスマーケティングに関する規制の具体的な線引きは、個別の表示方法によって判断が分かれる部分があります（2026年7月時点）

自分のサイトでの表示方法に迷う場合は、消費者庁の関連ガイドラインや専門家への確認をおすすめします。

## チェックリスト

| 確認項目 | 内容 |
| --- | --- |
| 文面 | 断定や煽りの表現がなく、事実ベースの短文になっているか |
| 主従関係 | サイト説明が主役で、PR注記がその補足になっているか |
| 視認性 | PR注記の文字サイズ・コントラストが読める範囲に保たれているか |
| 表示範囲 | ブログ配下など、必要なページにだけ表示されているか |

## まとめ・次に読む

PR開示は「隠す」対象ではなく、「警戒されにくい伝え方をする」対象。サイト説明を主役にして、PR注記はトーンを抑えつつも視認性は保つ。バランスの要点はここです。
