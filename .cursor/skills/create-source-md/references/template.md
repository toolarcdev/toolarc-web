## Output Contract

1. **想定読者（1行）** — **上のペルソナを1行に要約**（別軸の読者像を立てない。初稿 `target` も同文）
2. **検索意図** — How-to / 比較 / チェックリスト / Hub
3. **主キーワードと副キーワード**
4. **記事の結論（3〜5点）** — `> **今日の結論**` に使う
5. **構成案（H2中心・最大5前後）** — 詳細は下の「構成の骨格」
6. **収益導線案** — アフィ／広告配慮／デジタル商品CTA（本数・弱リンク先）
7. **内部リンク候補（既存／未公開）** — `/blog/slug`。未公開は「準備中」（slug を出さない）
8. **免責文（見出しにしない）** — writing-rules 本命形式。日付は①の Get-Date

## Claude.ai 制約（リポジトリ非参照前提）

本 source だけ添付して本文初稿を書く。

### Frontmatter（初稿先頭）

```yaml
---
title: "…"
description: "120〜160文字必須（両端含む。①で再実測）"
date: YYYY-MM-DD
tags:
  - …
site: toolarc.jp
target: "ペルソナを要約した想定読者1行（Output Contract 項目1と同文）"
---
```

- `target` はペルソナ表の別軸ではない。公開・初稿ではペルソナ表を転載せず、この1行で足りる

### 文体・形式（要約・正本は writing-rules）

- 敬体ベース。段落末は敬体。です／ます3連続の切断は必須にしない（L1任意。リズム目的の短文メタを増やさない）
- 結論先延ばし禁止。「今日の結論」を導入直後
- `――` / `——` 禁止（区切りは `｜` または句点分割）
- 括弧の入れ子禁止。未公開は `「準備中」`
- 内部リンクは `/blog/slug` のみ
- 空句は llm-forbidden-phrases の類型を避ける（重要なのは／掘り下げる／包括的／さらに連打 等）

### やらない（再掲）

- 隣接記事の全文転記、未確認断定、source に無い URL の捏造、直アフィ方針違反、posts／公開／PR
